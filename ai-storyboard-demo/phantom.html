03 · AI Image Prompts

Locked Prompt Set

Same discipline as Same Bread: four locked blocks — style, two character locks, location — then the shot. Every panel generated from these; paste-ready.

SARAH — CHARACTER LOCK

Early 30s woman, black bob with straight bangs, clear glasses, long camel trench coat over dark turtleneck, black gloves, calm focused expression, carries a slim tablet device.

SPIKE — CHARACTER LOCK

Late 20s man, short platinum-blond undercut, dark leather-synth coat over grey hoodie, black fingerless gloves, cocky half-smile, carries a slate tablet, lean build.

LOCATION LOCK

High-security server vault: towering black server racks with green status lights lining a long corridor, glass biometric lock panel with red/green circuit traces, central glowing green data sphere in a circular chamber, cold volumetric green haze, dark metal floor grates.

STYLE LOCK

Comic-book storyboard style, landscape 16:9, bold ink outlines, teal-green and magenta duotone lighting, cold cyberpunk palette, cinematic composition, halftone shading. No watermark, no logo.

CONTINUITY DISCIPLINE

One Gemini thread for all nine panels — Sarah's bob+glasses+camel coat and Spike's platinum undercut locked in words and re-checked on every gen; the green sphere and rack corridor kept as fixed geography; SFX lettering specified per panel so the model never invents its own.

WHAT THIS SHOWS

A different genre (cyberpunk action), a different visual style (graphic-novel vs photoreal), same locked-prompt workflow — the loop transfers to whatever script your production brings.
