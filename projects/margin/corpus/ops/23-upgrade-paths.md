# Account Tiers, Add-ons and Upgrades

## Tier comparison

| Feature | Evaluation | Funded Standard | Funded Swing |
|---------|------------|-----------------|--------------|
| Weekend hold | no | no | futures only |
| News trading | restricted | yes | yes |
| Leverage | full | full | futures only, 50% margin |
| Monthly cost | none | none | $25 add-on |
| Drawdown type | static 10% | trailing post-payout | trailing post-payout |

## Add-ons

| Add-on | Price | Effect |
|--------|-------|--------|
| Swing upgrade | $25/mo | weekend holding (≥$50k accounts) |
| No-consistency badge | $99 one-time | removes the 40% best-day cap on payouts for that account |
| Bi-weekly → weekly payouts | $49/mo | payout window halves |
| Firm VPS | $15/mo | NY4 region, free at $100k+ |

## Upgrades

- Evaluation → funded is automatic on pass; the trader signs the funded
  agreement and completes KYC before the first trade on the funded account.
- Standard → swing: dashboard upgrade, prorated, takes effect next Monday.
- Size upgrades mid-cycle are not allowed (finish or reset the cycle first).

## The no-consistency badge

For systematic traders with lumpy days (event-driven styles), the $99 badge
often pays for itself in one cycle: a strategy whose best day is naturally
50% of monthly profit would otherwise wait multiple windows to withdraw.
